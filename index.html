SF-adjusted QB timing curve heuristic, not observed data

Superflex leagues draft QBs much earlier than 1QB ADP suggests (two starting slots instead of one). No tool here provides real 2QB ADP, so QB order is taken from 1QB ADP (a reasonable proxy for relative QB quality) and then compressed onto an early-pick curve — QB1 ≈ pick 4, roughly one additional startable QB coming off the board every 3-6 picks through the first five rounds, tapering after. This is a transparent, labeled estimate, not a fact — expect real draft-night variance around it.

Used for: every QB's "SF-adjusted ADP" figure and the Draft Plan's QB timing calls. Treat as directional, re-check the live board when a QB run starts.

How the live tracking actually works

This is a plain static page, hosted on Vercel, not a Claude artifact — that was a deliberate switch. Claude's artifact platform can host a live shared data store, but it either requires disabling public link sharing (so only people signed into the same Claude organization can open it) or a Claude session actively relaying picks in the background. Neither fit "Colby just opens a link." A static site sidesteps both problems:

  1. Sleeper's draft API (api.sleeper.app) is public, needs no login, and returns open CORS headers — confirmed directly against the live endpoint, not assumed from docs.
  2. This page's own JavaScript polls that API directly from your browser every 5 seconds while the Live Draft tab is open — no backend, no Claude session, no relay of any kind.
  3. Every viewer's browser is polling independently, so the pick log, both rosters, the "drafted" strikethrough on the player tables, and the on-the-clock indicator all update within a few seconds of a real pick, for anyone with the link — Colby included, with zero setup on his end.
  4. If Sleeper's API is briefly unreachable, the page keeps showing its last known state and quietly retries — no crash, no stale-looking error.

Net effect: real near-instant updates (bounded by the 5-second poll, not "whenever someone remembers to ask Claude"), fully public, and it keeps working even if no Claude session is open during the draft.

Terms, translated

You know rank distributions, comp drafts, and reading a scoreboard cold — football just has different vocabulary for the same ideas. Real definition first, then how it maps to a lobby you already understand.

Snake draft & pick notation

Pick order flips every round (1→10, then 10→1, then back). "1.04" reads Round 1, 4th overall. Because round 2 reverses, a fixed slot shows a different "pick-in-round" number in even rounds — same seat, different spot in that round's order.

Think of it like: a Bo3 veto that alternates ban/pick side — fair across the whole sequence, not just round one.

Tier vs. rank vs. ADP — three different things

Tier: a real talent cliff grouping. Rank: this board's projected-production order (NOT draft order — see the sourcing note above). ADP (average draft position): where players are actually, empirically taken in real drafts. Use tier for value, ADP for timing.

Think of it like: tier is a rank bracket (Immortal vs. Radiant), a raw points-rank is a stat leaderboard, and ADP is what pick people actually go in a real lobby — three different questions that only sometimes agree.

Dynasty position rank (in the expand panel)

Where a player ranks against others at his position on a superflex dynasty value board — a separate ranking from redraft rank or ADP. "RB3" means 3rd-most-valuable dynasty RB in the format, regardless of this year's draft order.

Think of it like: a prospect's ceiling rating vs. his current-season stat line.

Bye week

Every NFL team gets one week off. A player on bye scores zero and can't be started that week.

Think of it like: an operator pulled from the pool for a stretch — draft bench depth to cover it.

PPR (points per reception)

A point for every catch, on top of yards and touchdowns — boosts pass-catchers over pure yardage guys.

Think of it like: custom lobby rules that score objective time, not just kills.

Superflex / 2QB

This league starts two QBs, not one — QBs get drafted much earlier and hold value much longer than a normal league.

Think of it like: QB is your IGL. Most formats field one; this league fields two, so good ones go way ahead of the field.

Dynasty vs. redraft

Redraft wipes the roster every year. Dynasty keeps it — value has to include a player's whole future arc.

Think of it like: redraft is one tournament; dynasty is running an org across multiple splits.
